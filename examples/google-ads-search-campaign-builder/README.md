# Example data: google-ads-search-campaign-builder

Made up. Fernhill is a fictional crew scheduling software company and `fernhill-crew.example` is a placeholder domain. The keyword ideas, volumes and bids are invented for trying the skill. Nothing comes from a real ad account or a real Keyword Planner run.

- `keyword-planner.csv`: a Keyword Planner "Discover new keywords" download, with the title lines a download can carry.
- `brief.json`: the JSON brief the skill should produce, in Adwarp's launch format.
- `sample-output.md`: the human-readable brief, computed from the CSV and the inputs below.

Inputs used for the sample:

| Input | Value |
| --- | --- |
| Product | Fernhill: crew scheduling software for construction, landscaping and home service contractors |
| Landing page | https://www.fernhill-crew.example/crew-scheduling |
| Locations, language | United States, English |
| Daily budget | 120 USD |
| Highest CPC the user will pay | 12 USD |
| Target CPA | 150 USD |
| Conversion action | Demo request |
| Facts from the landing page | Drag and drop crew calendar; text alerts to crews; GPS clock-in; QuickBooks sync; plans from 49 USD a month; used by 1,200 contractors; 20 minute demo |
| Not sold | No free plan, no training, no airline, film or trucking use |
| Competitors not to bid on | Jobber, ServiceTitan, Housecall Pro |
