# Example data: google-ads-search-terms

Made up. Fernhill is a fictional crew scheduling software company, and every campaign, search term and number here is invented for trying the skill. Nothing comes from a real ad account.

- `search-terms.csv`: a Search terms report download for 30 days, with the title and date lines and the total row a Google Ads download can carry.
- `keywords.csv`: the Keywords report, used for the conflict check.
- `negative-keywords.csv`: the account's existing negatives, including a shared list and the campaigns it is applied to.
- `sample-output.md`: the report the skill should produce from these files, with the Editor CSV and the paste list.

Inputs used for the sample: target CPA 150 USD. Fernhill sells crew scheduling and dispatch software to construction, landscaping and home service contractors. It has no free plan, sells no training, and doesn't serve airlines, trucking, towing or emergency dispatch.
