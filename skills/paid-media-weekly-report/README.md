# Paid media weekly report

A fixed-format weekly report for LinkedIn Ads and Google Ads. The last 7 days against the 7 before, per platform and combined, with movers held to volume floors, launches and endings, flags, and exactly 3 actions. Built to run on a schedule. Works from CSV exports or live through Adwarp.

## Ask it

- "write the weekly paid report"
- "weekly ads report"
- "how did paid do this week"
- "Monday ads report"
- "week over week paid media"
- "weekly LinkedIn and Google Ads summary"

## Install

```bash
npx skills add adwarp-dev/paid-ads-skills
```

Or copy this folder into `~/.claude/skills/` or your agent's skills folder.

## How it runs

From a CSV export with nothing connected, or live through [Adwarp](https://adwarp.dev), the free, open-source MCP server and CLI for LinkedIn Ads and Google Ads. Adwarp setup: [adwarp.dev/docs/install](https://adwarp.dev/docs/install).

More on adwarp.dev: [adwarp.dev/linkedin-ads/reporting](https://adwarp.dev/linkedin-ads/reporting), [adwarp.dev/google-ads/reporting](https://adwarp.dev/google-ads/reporting), [adwarp.dev/how-it-works](https://adwarp.dev/how-it-works).
