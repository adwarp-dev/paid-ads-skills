# LinkedIn Ads lead drivers

Rank which LinkedIn ads actually produce leads or conversions and which burn budget without converting. A drivers table, a pause list with the money each ad burned, a check that separates Lead Gen Form problems from ad problems, and the hooks, offers and formats that win head to head inside the same ad set, so you know what to make next. Works from a Campaign Manager ad performance export or live through Adwarp.

## Ask it

- "which LinkedIn ads drive leads"
- "which LinkedIn ads don't convert"
- "cost per lead by ad"
- "which ads should I pause for not converting"
- "which creative is working"
- "what copy angle converts on LinkedIn"
- "what LinkedIn ads should we make next"

## Install

```bash
npx skills add adwarp-dev/paid-ads-skills
```

Or copy this folder into `~/.claude/skills/` or your agent's skills folder.

## How it runs

From a CSV export with nothing connected, or live through [Adwarp](https://adwarp.dev), the free, open-source MCP server and CLI for LinkedIn Ads and Google Ads. Adwarp setup: [adwarp.dev/docs/install](https://adwarp.dev/docs/install).

More on adwarp.dev: [adwarp.dev/linkedin-ads/reporting](https://adwarp.dev/linkedin-ads/reporting), [adwarp.dev/linkedin-ads/optimization](https://adwarp.dev/linkedin-ads/optimization).
